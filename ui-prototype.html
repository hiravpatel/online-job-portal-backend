Seeker Role Flow
1. Register / Login

JWT issued with role `SEEKER`.

2. Build profile + apply jobs

Resume upload, application submission, and application tracking.

3. Social actions

Follow users, create posts, like and comment. These generate notification records.

Company Role Flow
1. Register / Login

JWT issued with role `COMPANY`.

2. Post new job

New jobs remain pending until admin approval.

3. Manage applications

Update application status and review candidate profiles.

Admin Role Flow
1. Seeded admin login

Comes from env: `ADMIN_EMAIL` + `ADMIN_PASSWORD`.

2. Approvals + moderation

Approve/reject jobs, block/unblock users, filter users by role.

3. Observe system health

Monitor pending queue and notification delivery outcomes.

Admin Seeder Config
ADMIN_EMAIL="admin@jobportal.com" ADMIN_PASSWORD="Admin@123" ADMIN_FORCE_RESET_PASSWORD="false" npm run seed:admin # Also runs automatically on server boot

Runtime Event Chain
API hits SocialController

Example: `POST /api/social/posts/{postId}/comment`

SocialUseCases executes action

Core action saves follow/post/like/comment first.

NotificationUseCases enqueues records

Creates `PENDING` entries in `Notification` collection.

Cron worker delivers + updates status

`PENDING` -> `SENT` or `FAILED`.
